# VNStudio ドキュメント

VNStudio は、レトロスタイルとモダンな演出を組み合わせたノベルゲームエンジンです。
シンプルなスクリプトで台詞・背景・立ち絵・演出・分岐を書き、同じスクリプトを複数のランタイムで動かせます。

| ランタイム | 画面 | 入手方法 |
|---|---|---|
| Windows (Unity) | 1920×1080 基準 (16:9) | 基本セットに同梱 |
| XZ80 | 256×212 / 384×240 | エディタで初めて選んだときに自動でダウンロード |
| MSX (V9990) | 384×240 | 同上 |
| PSP | 480×272 | 同上 |
| X68000 | 320×256 | 同上 |
