# スクリプトの基本構文

## ファイル

- スクリプトは拡張子 `.scn` のテキストファイルです (UTF-8)。
- 1 行に 1 コマンドを書きます。空行は無視されます。

## コメント

行の先頭に `//` を書くと、その行はコメントになります。

```text
// ここから第1章
bg classroom
```

!!! warning "行末のコメントは使わないでください"
    Windows (Unity) ランタイムでは `wait 1.0 // 1秒待つ` のような行末のコメントも無視されます。しかし、ほかのランタイムでは行末のコメントを取り除かないため、コマンドが正しく解釈されない場合があります。
    コメントは必ず行を分けて、行の先頭に書いてください。

## 台詞

| 書き方 | 意味 |
|---|---|
| `"テキスト"` | 地の文 |
| `名前 "テキスト"` | 話者名付きの台詞 |
| `say 名前 "テキスト"` | 上と同じ (`say` を明示) |

## ラベル

`label <名前>` で、`jump`・`if`・選択肢の移動先を定義します。ラベル名は大文字と小文字を区別します。

## 変数

整数の変数を使えます。最初に `int` で宣言し、以後は `変数 = 値` で代入できます。

```text
int route = 0
route = 2
```

Windows (Unity) 以外のランタイムには、次の制限があります。

- 変数は 64 個まで、値は 16 ビット符号付き整数 (-32768〜32767) です。
- 式は `値`、`変数 + 数値`、`変数 - 数値` の形だけに対応します。
- `call` の入れ子は 8 段までです。

## 座標

`show`、`move`、`ui_anim`、`ui_choice` の座標は、1920×1080 の画面の **中央を原点 (0, 0)** とする値で書きます。X は右が正、Y は上が正です。
Windows (Unity) 以外のランタイムでは、この座標をそれぞれの画面サイズへ自動で換算します。

## ファイルの置き場所

| 種類 | フォルダ |
|---|---|
| 背景 | `Resources/Backgrounds/` |
| キャラクター | `Resources/Characters/<キャラID>/` |
| UI 画像 (ウィンドウ・アイコン) | `Resources/UI/` |
| BGM・MML | `Resources/Audio/BGM/` |
| 効果音 | `Resources/Audio/SE/` |
| ボイス | `Resources/Audio/VOICE/<キャラ名>/` |

ファイル名は拡張子を付けずに指定します。
