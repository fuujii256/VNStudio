## show — キャラクターを表示 {#show}

キャラクターを表示、または表情差分を変更します。

**書式**

```text
show <キャラID> <差分...> [x] [y] [scale]
```

`Resources/Characters/<キャラID>/` の画像を立ち絵として表示します。すでに表示中のキャラクターに実行すると、差分 (表情) を切り替えます。
差分がサブフォルダにある場合は、空白で区切って指定します (例: `show alice casual smile`)。
座標は画面中央を (0, 0) とする 1920×1080 基準の値で、省略すると中央・倍率 1.0 になります。

| 引数 | 説明 |
|---|---|
| `キャラID` | キャラクターのフォルダ名。 |
| `差分` | 画像ファイル名 (拡張子なし)。サブフォルダは空白区切り。 |
| `x / y` (省略可) | 表示位置。画面中央が (0, 0)。 |
| `scale` (省略可) | 表示倍率。 |

**例**

```text
show alice smile
show alice angry 200 -300 1.2
```

|---|:-:|---|

## hide — キャラクターを消す {#hide}

キャラクター、または ui_anim の表示を消します。

**書式**

```text
hide <キャラID>
hide ui_anim
```

指定したキャラクターを非表示にします。`hide ui_anim` で `ui_anim` の表示を消すこともできます。

**例**

```text
hide alice
```

## move — キャラクターを移動 {#move}

キャラクターを指定位置へ移動します。

**書式**

```text
move <キャラID> <x> <y> <秒数> [ease]
```

キャラクターを指定座標まで、指定秒数をかけて移動します。

| 引数 | 説明 |
|---|---|
| `x / y` | 移動先の座標 (`show` と同じ座標系)。 |
| `秒数` | 移動にかける時間。 |
| `ease` (省略可) | `linear` (既定) / `easein` / `easeout` / `easeinout`。 |

**例**

```text
move alice 500 0 1.0 easeout
```

**対応ランタイム**

| ランタイム | 対応 | 補足 |
|---|:-:|---|

| PSP | ○ |  |
| X68000 | ○ |  |
