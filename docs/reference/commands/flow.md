## label — ラベルを定義 {#label}

## call / return — サブルーチン {#call}

別スクリプトを呼び出し、return で呼び出し元へ戻ります。

**書式**

```text
call <ファイル名>
return
```

別のスクリプトファイルをサブルーチンとして呼び出します。呼び出された側で `return` を実行すると、呼び出し元の次の行へ戻ります。
`call cgmode` / `call savemode` / `call loadmode` は組み込み画面の呼び出しです ([セーブ・メニュー・CG](system.md) を参照)。

**例**

```text
call common_event
"イベントから戻ってきました。"
```

## int / set / add — 変数 {#int}

整数変数を宣言・代入・加算します。

**書式**

```text
int <変数> = <式>
<変数> = <値>
set <変数> <値>
add <変数> <値>
```

整数の変数を宣言し、値を代入します。宣言済みの変数は `int` を付けずに `変数 = 値` で代入できます。`set` と `add` も使えます。
変数の値はセーブ／ロードで保存・復元されます。

**例**

```text
int score = 0
score = score + 10
add score 5
set flag_met 1
```

## switch / case / default — 値による分岐 {#switch}

変数の値と一致する case へ分岐します。

**書式**

```text
switch <変数>
case <値>
default
```

変数の値に応じて、一致する `case` へ分岐します。どの `case` にも一致しない場合は `default` へ進みます。
条件が単純なら `if`、値ごとに分岐が増えるなら `switch` が読みやすくなります。

**例**

```text
switch route
case 1
jump RouteA
case 2
jump RouteB
default
jump RouteCommon
}
```
