## choice — 選択肢 {#choice}

縦並びの選択肢を表示し、選ばれた項目のラベルへ移動します。

**書式**

```text
choice
"選択肢" -> <ラベル>
```

`choice` の次の行から、`"表示文" -> ラベル` の形で選択肢を並べます。選んだ項目のラベルへ移動します。
選択肢の見た目は `config choicewindow` で変更できます。

**例**

```text
choice
"元気です！" -> LabelGood
"まあまあです" -> LabelNormal
```

## ui_choice — 位置指定の選択肢 {#ui-choice}

座標・文字サイズ・色を指定できる選択肢を表示します。

**書式**

```text
ui_choice
"選択肢" [x] [y] [size] [color] -> <ラベル>
```

タイトル画面やメニュー画面などで使う、位置を指定できる選択肢です。

- 色を省略すると、`config text color` の色になります。
- `slot=N` を付けると、セーブデータのサムネイルと日時を表示します (セーブ画面用)。

**例**

```text
ui_choice
"Start" 0 100 36 #FFFFFF -> LabelStart
"Exit"  0 200 24 #AAAAAA -> LabelExit
```

**対応ランタイム**

| ランタイム | 対応 | 補足 |
|---|:-:|---|
| Windows (Unity) | ○ |  |
| XZ80 | △ | 位置は画面内に収まるよう調整します。文字サイズと色の指定は無視します。 |
| MSX (V9990) | △ | 位置は画面内に収まるよう調整します。文字サイズと色の指定は無視します。 |
| PSP | △ | 文字サイズと色の指定は無視します。 |
| X68000 | △ | 位置・文字サイズ・色の指定は無視し、下部の選択肢領域に中央揃えで表示します。 |
