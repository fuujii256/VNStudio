# XZ80 専用設定 (configXZ80)

XZ80 ランタイムの画面モードや複数画面構成を設定するコマンドです。ほかのランタイムでは読み飛ばされます。

!!! note "対応ランタイムの記号"
    ○ 対応 / △ 一部対応 / × 非対応 (読み飛ばし) / — 準備中

---

## configXZ80 screenmode — 画面モード {#configxz80-screenmode}

XZ80 の解像度と色形式を切り替えます。

**書式**

```text
configXZ80 screenmode <1〜4>
configXZ80 <1〜4>
```

以後の背景画像の変換・読み込み・画面初期化に使う画面モードを設定します。既定は `4` です。フォントも自動で切り替わります。

| モード | 解像度 | 色形式 | フォント |
|---|---|---|---|
| `1` | 256×212 | 256 色 (インデックス) | 8×8 美咲フォント |
| `2` | 256×212 | 32768 色 (ダイレクト) | 8×8 美咲フォント |
| `3` | 384×240 | 256 色 (インデックス) | 12×8 k12x8 |
| `4` | 384×240 | 32768 色 (ダイレクト) | 12×8 k12x8 |

**例**

```text
configXZ80 screenmode 2
```

## configXZ80 combiMode / outputMode — 複数画面構成 {#configxz80-combimode}

複数画面の論理配置と出力方式を設定します。

**書式**

```text
configXZ80 combiMode <0〜15>
configXZ80 outputMode <single|triple>
configXZ80 gap <0〜255>
configXZ80 bezel <on|off>
configXZ80 rotateDir <cw|ccw>
```

`combiMode` でパネル数 (1〜3)、画面の向き、並べ方を設定します。`outputMode` は物理的な出力方式、`gap` はパネル間の隙間 (ピクセル)、`bezel` はベゼル表示、`rotateDir` は縦画面の回転方向です。

| 番号 | 画面の向き | パネル数 | 並べ方 |
|---|---|---|---|
| `0` | 横 | 1 | — |
| `1` | 縦 | 1 | — |
| `2` | 横 | 2 | 横に並べる |
| `3` | 縦 | 2 | 横に並べる |
| `4` | 横 | 2 | 縦に並べる |
| `5` | 縦 | 2 | 縦に並べる |
| `6` | 横 | 3 | 縦に並べる |
| `7` | 縦 | 3 | 縦に並べる |
| `8`〜`11` | 横／縦 | 2〜3 | 独立配置 |
| `15` | 横 | 3 | 横に並べる |

`outputMode triple` の値は保持しますが、現在の表示は 1 つのウィンドウへの合成です。

**例**

```text
configXZ80 combiMode 2
```

## configXZ80 speed — 早送り {#configxz80-speed}

ランタイム全体の早送り倍率を設定します。

**書式**

```text
configXZ80 speed <1|2|4|8>
```

`1` が標準速度 (60fps) です。`2`/`4`/`8` にすると、テキスト送り・`wait`・`fade` などすべてが一様に速くなります。
2 倍以上のときは音声をミュートします。`speed 1` に戻すと音声も戻ります。

**例**

```text
configXZ80 speed 4
configXZ80 speed 1
```

**対応ランタイム**
