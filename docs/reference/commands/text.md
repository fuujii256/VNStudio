## say — 台詞を表示 {#say}

メッセージを表示し、クリックまたはオートモードの待機後に次へ進みます。

**書式**

```text
say [名前] "テキスト"
"テキスト"
名前 "テキスト"
```

テキストウィンドウにメッセージを表示し、入力を待ちます。`say` は省略でき、`"テキスト"` だけの行は地の文、`名前 "テキスト"` の行は話者名付きの台詞になります。
文字の表示速度は `config text speed`、オートモード時の待ち時間は `config text wait` で設定します。表示中に決定キーを押すと全文を即時表示します。

| 引数 | 説明 |
|---|---|
| `名前` (省略可) | 話者名。省略すると地の文になります。 |
| `テキスト` | 表示する文章。`"` で囲みます。 |

**例**

```text
say "はじめまして！"
say しるふぁ "わたしがナビゲーターです"
"こんにちは"
アリス "よろしくね"
```

## wait — 指定時間待つ {#wait}

指定した秒数だけ待機します。

**書式**

```text
wait <秒数>
```

指定した秒数だけ待機します。秒数は小数で指定できます (例: `0.5`)。

| 引数 | 説明 |
|---|---|
| `秒数` | 待機する時間 (秒)。 |

**例**

```text
wait 1.0
```

## clear — 画面をクリア {#clear}

背景、立ち絵、メッセージ、ui_anim などの表示をクリアします。

**書式**

```text
clear
```

背景 (スクロール中の背景を含む)、立ち絵、メッセージ、選択肢、`ui_anim` の表示をすべて消去します。章の切り替えなどに使います。

**例**

```text
fade out 1.0
```
