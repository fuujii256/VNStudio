# 背景

背景画像の表示とスクロールに関するコマンドです。画像は `Resources/Backgrounds/` に置き、拡張子を付けずに名前で指定します。

## bg / bg0 — 背景を表示 {#bg}

最背面の背景レイヤーに画像を表示します。

**書式**

```text
bg <画像名>
bg0 <画像名>
```

最背面の背景レイヤー (レイヤー 0) に画像を表示します。`bg` と `bg0` は同じ意味です。
画像は `Resources/Backgrounds/` を最初に探し、見つからなければ `Resources/` 配下の全フォルダを探します。同じ名前の画像が複数あると誤表示を防ぐため読み込まないので、その場合は `event/breakfast` のように `Resources/` からの相対パスで指定してください。
直後に `fade in` がある場合は、透明な状態で読み込んでからフェードインします。

| 引数 | 説明 |
|---|---|
| `画像名` | 拡張子を除いたファイル名、または `Resources/` からの相対パス。 |

**例**

```text
bg school_day
fade in 1.0
```

**対応ランタイム**

| ランタイム | 対応 | 補足 |
|---|:-:|---|
| Windows (Unity) | ○ | 動画ファイルを指定すると動画背景として再生します。 |
| XZ80 | ○ | 動画を指定した場合は、書き出し時に最終フレームの静止画へ変換して表示します。 |
| MSX (V9990) | ○ |  |
| PSP | ○ | 動画ファイルを指定すると動画背景として再生します。 |
| X68000 | ○ | 動画を指定した場合は、書き出し時に最終フレームの静止画へ変換して表示します。グラフィックページ 0 に表示します。 |

## bg1〜bg3 — 背景レイヤーを重ねる {#bg1}

指定した背景レイヤー (1〜3) に画像を重ねて表示します。

**書式**

```text

bg2 <画像名>

```

背景レイヤー 1〜3 に画像を重ねて表示します。透明部分のある画像を使うと、下のレイヤーに重ねられます。

| 引数 | 説明 |
|---|---|
| `画像名` | 拡張子を除いたファイル名。 |

**例**


## bg_scroll — 背景をスクロール {#bg-scroll}

背景を指定倍率で表示し、指定方向へ非同期でスクロールします。

**書式**

```text
bg_scroll <bg0|bg1> <画像名> <scale> <up|down|left|right> <秒数>
bg_scroll <bg0|bg1> stop
```

背景画像を指定倍率・開始端で直接表示し、指定秒数をかけて反対側の端まで移動して止まります。`bg` を先に実行する必要はありません。
スクロールは待たずに進むので、`say` や `choice` の間も動き続けます。ループや往復はしません。

- 方向は画像自体が動く向きです。
- `scale 1.0` は通常の背景と同じ大きさです。移動に必要な余白が作れない倍率の場合は、中央に表示します。
- `stop` を指定すると、現在の位置で止めます。
- 同じレイヤーに `bg` や `bg_scroll` を実行すると、前のスクロールは終了します。`clear` でも停止します。
- 対象は静止画像と `bg0`／`bg1` だけです。

| 引数 | 説明 |
|---|---|
| `bg0|bg1` | 対象の背景レイヤー。 |
| `画像名` | 拡張子を除いたファイル名。 |
| `scale` | 表示倍率 (1.0 = 通常サイズ)。 |
| `up|down|left|right` | 画像が移動する方向。 |
| `秒数` | 端から端まで移動する時間。 |

**例**

```text
bg_scroll bg0 tower_long 1.8 up 30
say "塔を見上げながら進んでいく。"
bg_scroll bg0 stop
```

| XZ80 | × | 非対応 (読み飛ばし) |
| MSX (V9990) | ○ |  |
| PSP | ○ |  |
| X68000 | ○ |  |
