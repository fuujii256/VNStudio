## fade — フェード {#fade}

画面、テキストウィンドウ、背景レイヤー、立ち絵をフェードします。

**書式**

```text
fade <in|out> [対象] [秒数]
```

黒からのフェードイン／黒へのフェードアウトを行います。対象を省略すると画面全体が対象です。

| 引数 | 説明 |
|---|---|
| `in|out` | フェードイン / フェードアウト。 |
| `対象` (省略可) | `screen` (省略時)、`textwindow`、`bg0`〜`bg3`、キャラID。 |
| `秒数` (省略可) | フェードにかける時間。 |

**例**

```text
fade out 1.0
bg school_night
fade in 1.0
```

```text
fade out bg1 0.5
```

| ランタイム | 対応 | 補足 |
|---|:-:|---|
| Windows (Unity) | ○ |  |

| PSP | ○ |  |

## ui_anim — UI アニメーション {#ui-anim}

画像または文字を UI レイヤーに表示し、アニメーションさせます。

**書式**

```text
ui_anim <画像名> <X> <Y> <scale> [mode] [秒数]
ui_anim text "<文字>" <X> <Y> <scale> [mode] [秒数]
```

画像または文字を指定座標に表示し、指定したモードでアニメーションさせます。画像は `Resources/UI/` を探し、見つからなければ `Resources/Backgrounds/` も探します。
文字の場合は、その時点の `config text font`／`size`／`color` の設定で表示します。空白を含む文字は `"` で囲みます。

| mode | 動き |
|---|---|
| `vertical` (既定) | 縦方向に回転するように伸縮を繰り返す |
| `horizontal` | 横方向に回転するように伸縮を繰り返す |
| `float` | 回転せず、上下にゆっくり揺れる |
| `fade` | 指定秒数の前半でフェードイン、後半でフェードアウトして自動で消える (秒数の指定が必要) |

次の `ui_anim`、`hide ui_anim`、`clear` で消えます。

| 引数 | 説明 |
|---|---|
| `X / Y` | 表示位置 (1920×1080 基準、画面中央が原点)。 |
| `scale` | 表示倍率。 |
| `mode` (省略可) | `vertical` / `horizontal` / `float` / `fade`。 |
| `秒数` (省略可) | `fade` モードの総表示時間 (0 より大きい値)。 |

**例**

```text
ui_anim Icon_Garden 500 200 0.9 float
ui_anim text "NEW EVENT" 500 200 1.0 fade 2.0
```

| XZ80 | × | 非対応 (読み飛ばし) |
| MSX (V9990) | × | 非対応 (読み飛ばし) |
| PSP | ○ |  |
