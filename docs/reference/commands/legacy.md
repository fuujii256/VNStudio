## OPNAPlay / OPLLPlay / FMStop — 旧 FM コマンド {#opnaplay}

旧コマンドです。fm play / fm stop を使ってください。

**書式**

```text
OPNAPlay <MMLファイル名>
OPLLPlay <MMLファイル名>
FMStop
```

それぞれ `fm play <MML> opna`、`fm play <MML> opll`、`fm stop` と同じ動作です。旧名 `FMPlay` も `OPNAPlay` の別名として使えます。

**対応ランタイム**

| ランタイム | 対応 | 補足 |
|---|:-:|---|
| Windows (Unity) | ○ |  |
| XZ80 | ○ |  |
| MSX (V9990) | △ | `OPLLPlay` と `FMStop` のみ対応します。 |
| PSP | × | 非対応 (読み飛ばし) |
| X68000 | △ | `FMStop` のみ (音声の停止として) 対応します。 |
