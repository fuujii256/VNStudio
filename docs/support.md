# お問い合わせ

VNStudio に関するご質問・不具合報告は、しるふぁ工房のお問い合わせページからお願いします。

**[しるふぁ工房 お問い合わせページ](https://fuujii256.github.io/sylfa-studio/contact.html)**

GitHub の Issues は受け付けていません。

## 不具合を報告するときは

次の情報を書いていただけると、原因を早く調べられます。

1. **VNStudio のバージョン**、使っているランタイム、Windows のバージョン
2. **起きたこと** と、本来どうなってほしかったか
3. **再現する手順** (どのスクリプトの、どの行を実行したときか)
4. 可能であれば、**画面のスクリーンショット**

うまくいかないときは、先に [FAQ](faq.md) と [ランタイム対応表](reference/runtime-support.md) もご確認ください。
