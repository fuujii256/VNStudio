# インストール

!!! info "最新版"
    最新版は [VNStudio 0.90.0-beta](https://github.com/fuujii256/VNStudio/releases/tag/v0.90.0-beta) です (ベータ版)。

## 動作環境

- Windows 10 / 11 (64 ビット)

## インストールの手順

1. [Releases](https://github.com/fuujii256/VNStudio/releases) から `VNStudio_<バージョン>.zip` をダウンロードします (例: `VNStudio_0.90.0-beta.zip`)。
2. **展開する前に**、zip を右クリック →「プロパティ」→「セキュリティ: 許可する」にチェック →「OK」を押します。詳しくは [SmartScreen の警告が出たとき](smartscreen.md) を参照してください。
3. 好きな場所に展開します。
4. 展開したフォルダの `START_VNStudio.bat` をダブルクリックすると、エディタが起動します。

基本セットには、エディタ、Windows (Unity) ランタイム、サンプルプロジェクト (`Resources`)、オフライン版ドキュメント (`Docs`) が入っています。エディタは .NET を同梱しているので、別途インストールする必要はありません。

!!! note "ほかのランタイムについて"
    0.90.0-beta で使えるのは Windows (Unity) ランタイムだけです。XZ80・MSX・PSP・X68000 のランタイムは、今後のバージョンで、エディタで初めて選んだときに自動でダウンロードできるようにする予定です。

## 更新

0.90.0-beta には自動更新の機能がまだありません。新しいバージョンが出たら、新しい zip を別のフォルダに展開し、作成中のプロジェクト (`Resources` フォルダ) を移してください。
今後のバージョンで、基本セットと各ランタイムを別々に自動更新できるようにする予定です。

## アンインストール

展開したフォルダを削除してください。エディタの設定は `%LOCALAPPDATA%\VNStudio` にあるので、不要であればこのフォルダも削除してください。
