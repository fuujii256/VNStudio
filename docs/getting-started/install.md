# インストール

!!! info "最新版"
    最新版は [VNStudio 0.92.1-beta](https://github.com/fuujii256/VNStudio/releases/tag/v0.92.1-beta) です (ベータ版)。

## 動作環境

- Windows 10 / 11 (64 ビット)

## インストールの手順

1. [Releases](https://github.com/fuujii256/VNStudio/releases) から `VNStudio_<バージョン>.zip` をダウンロードします (例: `VNStudio_0.92.1-beta.zip`)。
2. **展開する前に**、zip を右クリック →「プロパティ」→「セキュリティ: 許可する」にチェック →「OK」を押します。詳しくは [SmartScreen の警告が出たとき](smartscreen.md) を参照してください。
3. 好きな場所に展開します。
4. 展開したフォルダの `VNStudio.exe` (または `START_VNStudio.bat`) をダブルクリックすると、エディタが起動します。

基本セットには、エディタ、Windows (Unity) ランタイム、サンプルプロジェクト (`Resources`)、オフライン版ドキュメント (`Docs`) が入っています。エディタは .NET を同梱しているので、別途インストールする必要はありません。

!!! note "ほかのランタイムについて"
    PSP・X68000・MSX (V9990) のランタイムは **α 版** (一部の機能が未実装) で、エディタで初めて選んだときに自動でダウンロードします。準備の手順は [ほかのランタイムを使う](runtimes.md) を参照してください。XZ80 ランタイムは準備中です。

## 更新

0.92.0-beta 以降は、エディタの中から更新できます。

1. 新しい版があると、エディタ右上の「コンポーネント」ボタンが「更新があります」に変わります。
2. ボタンを押すと「コンポーネントの管理」画面が開きます。更新する項目を選んで「更新」を押します。
3. エディタ本体と Windows ランタイムは、ダウンロードが終わるとエディタを再起動して更新します (作成中のスクリプトは保存しておいてください)。PSP・X68000・MSX のランタイムは、その場で更新されます。

更新した版で不具合が出たときは、同じ画面の「以前の版に戻す」で、1 つ前の版に戻せます。
お問い合わせの際は、「環境情報をコピー」で版の情報をコピーして貼り付けてください。

!!! note "0.91.0-beta 以前をお使いの場合"
    0.91.0-beta 以前には更新の機能がありません。新しい zip を別のフォルダに展開し、作成中のプロジェクト (`Resources` フォルダ) を移してください。ダウンロード済みのランタイムは、そのまま使えます。

!!! warning "エディタは VNStudio.exe から起動してください"
    エディタ本体の更新は、`VNStudio.exe` (または `START_VNStudio.bat`) から起動したときに適用されます。`Editor\RSStudio.Editor.exe` を直接起動すると、更新が適用されません。

## アンインストール

展開したフォルダを削除してください。エディタの設定と、ダウンロードしたランタイムは `%LOCALAPPDATA%\VNStudio` にあるので、不要であればこのフォルダも削除してください。
