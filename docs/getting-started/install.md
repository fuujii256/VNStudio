# インストール

!!! info "最新版"
    最新版は [VNStudio 0.91.0-beta](https://github.com/fuujii256/VNStudio/releases/tag/v0.91.0-beta) です (ベータ版)。

## 動作環境

- Windows 10 / 11 (64 ビット)

## インストールの手順

1. [Releases](https://github.com/fuujii256/VNStudio/releases) から `VNStudio_<バージョン>.zip` をダウンロードします (例: `VNStudio_0.91.0-beta.zip`)。
2. **展開する前に**、zip を右クリック →「プロパティ」→「セキュリティ: 許可する」にチェック →「OK」を押します。詳しくは [SmartScreen の警告が出たとき](smartscreen.md) を参照してください。
3. 好きな場所に展開します。
4. 展開したフォルダの `START_VNStudio.bat` をダブルクリックすると、エディタが起動します。

基本セットには、エディタ、Windows (Unity) ランタイム、サンプルプロジェクト (`Resources`)、オフライン版ドキュメント (`Docs`) が入っています。エディタは .NET を同梱しているので、別途インストールする必要はありません。

!!! note "ほかのランタイムについて"
    PSP・X68000・MSX (V9990) のランタイムは、エディタで初めて選んだときに自動でダウンロードします。準備の手順は [ほかのランタイムを使う](runtimes.md) を参照してください。XZ80 ランタイムは準備中です。

## 更新

ダウンロード型のランタイム (PSP・X68000・MSX) は、新しい版が公開されると、ランタイムを選んだときに更新するかどうかを確認します。

基本セット (エディタと Windows ランタイム) には、自動更新の機能がまだありません。新しいバージョンが出たら、新しい zip を別のフォルダに展開し、作成中のプロジェクト (`Resources` フォルダ) を移してください。基本セットの自動更新は、今後のバージョンで対応する予定です。

## アンインストール

展開したフォルダを削除してください。エディタの設定と、ダウンロードしたランタイムは `%LOCALAPPDATA%\VNStudio` にあるので、不要であればこのフォルダも削除してください。
