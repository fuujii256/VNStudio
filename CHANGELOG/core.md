# 変更履歴 (基本セット: エディタ + Windows ランタイム)

## 0.90.0-beta (2026-09-24)

初めての公開ベータ版です。

- エディタ (Windows) と Windows (Unity) ランタイムを同梱した基本セットを公開しました。
- エディタは .NET を同梱した形で配布します。別途 .NET をインストールする必要はありません。
- Windows ランタイムは IL2CPP でビルドしています。
- サンプルプロジェクトと、オフライン版のドキュメント・コマンドリファレンスを同梱しました。
- エディタからのプレビュー時に、ランタイムとの通信が IL2CPP 環境で失敗する問題を修正しました。

### 既知の制限

- 使えるのは Windows (Unity) ランタイムだけです。XZ80・MSX・PSP・X68000 のランタイムは今後のバージョンで対応します。
- 自動更新の機能はまだありません。
- コード署名をしていないため、初回起動時に SmartScreen の警告が表示されることがあります。Windows 11 のスマート アプリ コントロールが有効な PC では起動できません。
