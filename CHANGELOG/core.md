# 変更履歴 (基本セット: エディタ + Windows ランタイム)

## 0.92.6-beta (2026-09-26)

- Windows (Unity): 配布用に書き出したゲームを起動したとき、まれに別の作品の画像やスクリプトが表示されることがある不具合を修正しました。
    - Windows ランタイムは、配布パッケージ (`game.pak`) の中のスクリプトと素材だけを読み込み、パソコン内にある別の作品のフォルダを探しに行かないようにしました。
    - エディタの「パブリックフォルダを開く」で Windows 向けの配布 ZIP を作るときは、いま選んでいるプロジェクトだけを対象にし、開くたびに作り直すようにしました。
- この版では、エディタ本体と Windows (Unity) ランタイムの両方を更新しています。
    - すでに配布したゲームには、この修正は反映されません。この版で配布用ファイルを作り直してください。

## 0.92.5-beta (2026-09-25)

- X68000: 起動用のハードディスクイメージ (HDF) を、エディタで作れるようにしました。
    - X68000 LIBRARY で無償公開されている Human68k 3.02 のシステムディスク (`HUMN302I.LZH`) をダウンロードし、設定画面の「Human68k 3.02 から作成...」で選ぶと、PX68k で起動する HDF (60MB) を作ります。
    - 作成の前に、Human68k の許諾条件の要点を表示します。起動 HDF はプレビュー用です。有償の作品には同梱しないでください。
- X68000: HDF の更新に失敗したとき、rb-cli のエラー内容を表示するようにしました。
- Windows ランタイムは 0.92.0-beta のままです (更新はエディタ本体だけです)。

## 0.92.4-beta (2026-09-25)

- X68000: HDF 更新ツール (rb-cli) は、常に自動でダウンロードしたものを使うようにしました。設定画面の「HDF updater」欄はなくなりました。
- ダウンロードしたツール (rb-cli・共通ツール・PPSSPP) の実行ファイルがなくなっていたときは、自動でダウンロードし直すようにしました。
    - ダウンロード直後に実行ファイルが消えた場合は、ウイルス対策ソフトによる隔離の可能性を案内します。Windows セキュリティの「保護の履歴」で許可してください。
- Windows ランタイムは 0.92.0-beta のままです (更新はエディタ本体だけです)。

## 0.92.3-beta (2026-09-25)

- X68000: 設定画面で「HDF 更新ツール」や「RetroArch」に実行ファイル (.exe) 以外を指定したとき、設定の誤りとして扱い、設定画面を開くようにしました。
    - これまでは、HDF などを指定すると設定画面が開かなくなり、設定を直せませんでした。
    - HDF 更新ツールの指定が .exe でないときは、自動でダウンロードした rb-cli に戻します。
- X68000: プレビューでエラーが出たときに、設定画面を開いて確認できるようにしました。
- Windows ランタイムは 0.92.0-beta のままです (更新はエディタ本体だけです)。

## 0.92.2-beta (2026-09-25)

- MSX: プレビューの前に、FS-A1GT のシステム ROM (`fs-a1gt_firmware.rom`・`fs-a1gt_kanjifont.rom`) を中身で確認するようにしました。足りないときは、不足しているファイル名を案内します。
    - これまでは `systemroms` フォルダに何かの ROM があれば先に進み、openMSX が「exit code 1」で終了していました。
- MSX: openMSX が起動直後に終了したときのエラーに、ROM の確認と準備の手順ページへの案内を加えました。
- X68000: RetroArch の入手先の案内を、libretro 公式の配布サーバー (buildbot.libretro.com) に変えました。
- Windows ランタイムは 0.92.0-beta のままです (更新はエディタ本体だけです)。

## 0.92.1-beta (2026-09-25)

- エディタのダイアログ (エラーや案内) に書かれた URL を、クリックするとブラウザで開けるようにしました。
- ダイアログの本文を Ctrl+C でコピーできます。お問い合わせの際にお使いください。
- Windows ランタイムは 0.92.0-beta のままです (更新はエディタ本体だけです)。

## 0.92.0-beta (2026-09-25)

- エディタの中から、エディタ本体・Windows ランタイム・各ランタイムを更新できるようにしました。
    - エディタ右上の「コンポーネント」ボタンから「コンポーネントの管理」画面を開けます。新しい版があるときは「更新があります」と表示します。
    - 更新した版で不具合が出たときは、「以前の版に戻す」で 1 つ前の版に戻せます。
    - 「環境情報をコピー」で、お問い合わせに使う版の情報をコピーできます。
- Windows (Unity) 以外のランタイム (PSP・X68000・MSX・XZ80) が α 版で、一部の機能が未実装であることを、ドキュメントとエディタの表示で明記しました。
- ランタイムの動作に新しいエディタが必要な場合は、ダウンロード・更新の前に「先にエディタを更新してください」と案内するようにしました。
- 基本セットに起動用の `VNStudio.exe` を追加しました。
- サンプルプロジェクトのメニューの「設定」を、オートモード・テキスト速度・BGM/SE/ボイス・システム音を設定できる共通の設定画面 (`settingsmenu`) にしました。
- 「パブリックフォルダを開く」ボタンで、選んでいるランタイム向けの配布用ファイルを作り (まだ作っていないとき・古いとき)、そのフォルダを開くようにしました (Windows: ゲーム一式の ZIP、PSP: メモリースティック用フォルダ、MSX: カートリッジ ROM、X68000: 実行ファイルとデータ一式)。「Build Package」ボタンはこれに統合して廃止しました。
- 配布用ファイルの素材とスクリプトを、作品ごとに異なる鍵で暗号化するようにしました (Windows: AES-256、PSP・X68000: 簡易暗号、MSX: スクリプトのみ簡易暗号)。
- Windows 向けの配布 ZIP に、ライセンス表記 (`THIRD-PARTY-NOTICES.txt`) を入れるようにしました。
- 配布版で「パブリックフォルダを開く」が開けなかった問題を修正しました。
- ドキュメントに「作品を配布する」ページを追加しました。エディタ本体と Windows ランタイムの更新は、ここから起動したときに適用されます。

### 既知の制限

- 0.91.0-beta 以前からは自動で更新できません。0.92.0-beta の zip を新しく展開してください。
- XZ80 ランタイムは準備中です。

## 0.91.0-beta (2026-09-24)

- PSP・X68000・MSX (V9990) のランタイムを、エディタで初めて選んだときに自動でダウンロードして使えるようにしました。ツールチェーンや Node.js のインストールは不要です。
    - ダウンロードしたランタイムは、基本セットとは別に更新できます。
    - 配布情報は署名で、ダウンロードしたファイルはハッシュ値で検証します。
- PSP: エミュレータ PPSSPP を公式サイトから自動でダウンロードするようにしました。
- X68000: RetroArch・ROM・起動 HDF が見つからないときに、準備の手順と設定画面を表示するようにしました。
- X68000: プレビュー時のメモリを 12MB にして、大きな BGM も読み込めるようにしました。
- MSX: openMSX とシステム ROM が見つからないときに、準備の手順を表示するようにしました。
- XZ80 の画面モードの既定値を 4 から 3 に変更しました (モード 4 の表示不具合のため)。
- PSP 向けの書き出しで、ランタイムが受け付けない設定命令を出力していた問題を修正しました。
- サンプルプロジェクトに、`show item diamond` で表示するアイテム画像の例を追加しました。

### 既知の制限

- XZ80 ランタイムは準備中です。
- MSX は V9990 (GFX9000) 向けの映像だけに対応しています。
- MSX では、台詞の中の `\n` (改行) がそのまま文字として表示されます。
- 基本セットの自動更新の機能はまだありません。

## 0.90.0-beta (2026-09-24)

初めての公開ベータ版です。

- エディタ (Windows) と Windows (Unity) ランタイムを同梱した基本セットを公開しました。
- エディタは .NET を同梱した形で配布します。別途 .NET をインストールする必要はありません。
- Windows ランタイムは IL2CPP でビルドしています。
- サンプルプロジェクトと、オフライン版のドキュメント・コマンドリファレンスを同梱しました。
- エディタからのプレビュー時に、ランタイムとの通信が IL2CPP 環境で失敗する問題を修正しました。

### 既知の制限

- 使えるのは Windows (Unity) ランタイムだけです。XZ80・MSX・PSP・X68000 のランタイムは今後のバージョンで対応します。
- 自動更新の機能はまだありません。
- コード署名をしていないため、初回起動時に SmartScreen の警告が表示されることがあります。Windows 11 のスマート アプリ コントロールが有効な PC では起動できません。
